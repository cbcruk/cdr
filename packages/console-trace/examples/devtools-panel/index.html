console-trace · devtools panel

A TanStack-Devtools-style interface built on the public API. Click the trace launcher (bottom-right) to open the panel: pick a span on the left to inspect its timing, source link, and logs on the right. Everything updates live as traced work runs.

Use the buttons to drive the traced checkout workload. The second one overflows the payment limit so you can see an error span and a warn log.
